# Netting Dashboard — браузер и macOS

Рядом с заголовком каждой карточки есть вопросительный знак с подсказкой Gravity UI: наведите курсор или переведите фокус, чтобы увидеть формулу расчёта, столбцы и правила обработки пропусков. Фильтры дат используют фиксированный формат дд/мм/гггг с ручным вводом и выбором через календарь. Несуществующие даты не применяются и подсвечиваются ошибкой.

В боковом меню доступны «Обзор показателей» (все карточки), «Total» (показатели и график TOTAL) и «Fixed USD Amount» (показатели U и пайчарт валют). «Данные по дням» и «Проверьте даты в Excel» показаны во всех разделах. Раздел «Курс» показывает средний курс сегодня, средний курс за период и процентное изменение к предыдущему дню, а также две общие карточки. Карточки курса также остаются в общем обзоре. Фильтр дат общий; порядок карточек сохраняется отдельно для каждого раздела, включая прежний порядок общего обзора.

Карточки можно перемещать за ручку ⠿: они выравниваются по сетке, соседние переставляются во время переноса. Порядок сохраняется между запусками. Доступен перенос с клавиатуры: фокус на ручке, пробел, стрелки, пробел для завершения или Escape для отмены. Графики и таблица занимают всю ширину сетки.

Логотип интерфейса и иконка macOS создаются из `public/netting-logo.svg`. Для повторного создания иконки: `npm run build:icon`. Справа вверху отображается «Powered by LSD».

Значения изменений TOTAL и курса окрашиваются по знаку: отрицательные — красные, нулевые и отсутствующие — синие, положительные — зелёные. Во время загрузки и обновления карточки показывают анимированный скелетон с сохранением размеров; при отключённых системных анимациях скелетон статичен. Валюты, суммы и проценты размещены в адаптивной легенде внутри карточки пайчарта; значения при наведении на сектора остаются доступными.

Приложение React + Gravity UI UIKit и Charts. В браузере входит через Microsoft 365 и читает Excel из OneDrive; версия Electron для macOS читает локальную книгу через кнопку «Открыть Excel». Обе версии показывают график, карточки и таблицу с фильтром дат и проверяют обновления раз в минуту.

В версии для macOS выбранный путь сохраняется в настройках приложения и автоматически открывается при следующем запуске. Один раз выберите синхронизируемый файл из папки OneDrive. Если файл перемещён или недоступен, приложение показывает ошибку; кнопка «Открыть Excel» позволяет выбрать новый источник.

Карточка `FIXED USD AMOUNT` суммирует сохранённые значения U из строк TOTAL за выбранный диапазон дат. Пропуски и ошибки U учитываются независимо от Y; блоки с неоднозначной датой исключаются из обоих показателей. Дневные значения U также представлены в таблице.

Карточки `FIXED USD AMOUNT · за период` и `FIXED USD AMOUNT · сегодня` показывают выбранный период и текущий день Asia/Dubai соответственно. Сегодняшний показатель не зависит от фильтра дат. Приложение называется Netting Dashboard; сохранённый источник восстанавливается также из настроек предыдущей версии TOTAL Dashboard.

Средний курс: простое арифметическое среднее числовых значений E в строках с датой A, без строк TOTAL и без взвешивания по сумме. Карточка «сегодня» использует текущую дату Asia/Dubai независимо от фильтра; среднее за период учитывает фильтр. Процентное изменение сравнивает сегодняшний средний курс с последней более ранней датой с числовым курсом. При отсутствии данных или нулевом предыдущем среднем отображается прочерк.

Пайчарт показывает доли валют L по сумме сохранённых числовых значений FIXED USD AMOUNT (U) в строках операций за выбранный период. Строки TOTAL не включаются повторно. Пустые значения и ошибки U исключаются; нулевые группы не рисуются. Отсутствующая валюта обозначается «Не указана». Если итог по валюте отрицательный, вместо пайчарта отображается пояснение.

Лист: `RUB Deals Rates`. Строки с текстом `TOTAL` в A содержат дневной итог `OUR PNL USD` в Y. Дата определяется по строкам операций между итогами. Блоки с несколькими датами исключаются из графика и отмечаются отдельно. Пустые итоги и ошибки формул не заменяются нулями. Нулевые сохранённые результаты учитываются. Используются сохранённые результаты формул: приложение не пересчитывает Excel и не открывает внешние ссылки книги.

По умолчанию диапазон заканчивается сегодняшним днём по Asia/Dubai; «Все даты» включает будущие строки. При ошибке обновления сохраняются прежние данные с уведомлением.

Для запуска требуется Node.js 22 или новее:

```sh
npm install
npm run dev
```

Во втором терминале: `npm run desktop`.

Сборка: `npm run package:mac`. Выпуск подписанного приложения требует настройки подписи Apple и notarization.

Для корпоративного подключения требуется регистрация публичного приложения в Microsoft Entra ID, идентификаторы приложения и арендатора, делегированные права чтения и вход через Microsoft. Client secret в десктопном приложении не нужен. Если OneDrive уже синхронизирует файл на Mac, можно выбрать его локальную копию: приложение будет перечитывать изменения, доставленные клиентом OneDrive.

## Веб-версия и Microsoft 365

В браузере приложение входит через MSAL (Authorization Code + PKCE) и читает выбранную книгу из собственного OneDrive пользователя или доступную ему общую книгу через Microsoft Graph с делегированным `Files.Read.All`. Папки и книги `.xlsx` доступны во встроенном выборе файла. При первом входе на каждом устройстве выберите нужную книгу. Ссылка общего доступа не публикуется в исходниках; для выбора не требуются права записи. Для общей книги используется Microsoft Search (POST /search/query) с делегированным Files.Read.All: поиск показывает файлы, доступные вошедшему пользователю. После выбора сохраняются идентификаторы диска и книги, и чтение идёт через /drives/{driveId}/items/{itemId}, а не через /me/drive. Поиск зависит от индексации Microsoft; новая общая книга может появиться с задержкой. Прямое разрешение короткой ссылки через /shares не используется, поскольку Microsoft документирует для него права записи.

Содержимое книги и рассчитанные показатели хранятся только в памяти вкладки. В localStorage сохраняются идентификатор/название выбранной книги для конкретной учётной записи и порядок карточек; MSAL использует sessionStorage для сеанса входа. При перезагрузке Excel читается заново; выход очищает данные интерфейса. После входа под другим пользователем источник восстанавливается отдельно. Постоянного кеша Excel и офлайн-режима нет.

Раз в минуту в видимой вкладке проверяется версия файла (cTag/eTag). Неизменившаяся книга повторно не загружается. После возврата во вкладку или восстановления сети выполняется проверка. При ошибке остаются предыдущие данные с уведомлением. Приложение использует сохранённые результаты формул Excel и не пересчитывает книгу.

Регистрация Microsoft Entra: SPA, tenant организации, делегированное разрешение `Files.Read.All`. Адреса возврата:

- `http://localhost:5173/`
- `https://ki4fus.github.io/dashboard/`

Client ID и Tenant ID в `src/oneDrive.ts` являются публичными идентификаторами. Client secret не используется. `Files.Read.All` технически разрешает чтение файлов пользователя шире выбранной книги; приложение обращается к выбранной книге и показывает папки или результаты поиска для её выбора.

Запуск: `npm ci`, затем `npm run dev`; открывайте именно `http://localhost:5173/`. Проверка: `npm run build`. Браузерные проверки с синтетической книгой: `node scripts/check-web.cjs` при запущенном dev-сервере и установленном Google Chrome на macOS. В этих проверках вход Microsoft имитируется; реальный вход, корпоративные политики и скачивание настоящей книги проверяются отдельно владельцем учётной записи.

## GitHub Pages

В Settings → Pages выберите Source: GitHub Actions. Workflow `Publish dashboard to GitHub Pages` запускается вручную из Actions → Run workflow; обычная отправка коммитов сайт автоматически не публикует. Репозиторий может оставаться приватным, если план GitHub поддерживает Pages для приватных репозиториев. Видимость репозитория автоматически не меняется. Опубликованный интерфейс обычно публичен, доступ к Excel требует входа Microsoft и разрешений OneDrive.

Для публикации: сначала подтвердить и отправить проверенный коммит, затем отдельно запустить workflow. Никакие файлы Excel, токены или ссылки на книгу в артефакт сайта не включаются.

## Интерфейс браузерной версии

Справа вверху находятся иконка солнца/луны и меню с действиями «Мой OneDrive», «Общие файлы», «Выйти». На телефоне в этом меню доступны также разделы дашборда. Выход требует подтверждения; «Остаться», Escape и нажатие вне окна сохраняют сеанс. Выбранная тема сохраняется на устройстве. Блок источника компактно показывает книгу, аккаунт и время проверки обновлений.

Календарь фильтра закрывается по выбору даты, повторному нажатию кнопки, клику/касанию снаружи и Escape. Поддерживаются стрелки, Home/End и Page Up/Page Down. Ручной ввод остаётся в формате дд/мм/гггг.

Общие книги показаны каталогом по расположению файлов из результатов Microsoft Search: OneDrive/SharePoint → папки → книги. Отображаются только доступные книги из загруженных результатов, а не всё содержимое чужого диска. Поиск по названию и загрузка следующих результатов сохраняются. Для каталога дополнительные разрешения не требуются.

Inter Variable с кириллицей поставляется вместе с сайтом; запросов к Google Fonts нет. Шрифт распространяется по SIL Open Font License 1.1; текст лицензии — `public/fonts/inter-LICENSE.txt`. Иконки интерфейса — SVG.
